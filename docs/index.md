# iCloud Calendar MCP

A personal, single-user [Model Context Protocol](https://modelcontextprotocol.io) server. It lets the
owner's Claude sessions read and manage the owner's own iCloud calendar.

- It isn't a public service. Sign-in with Google is used only to confirm that the person connecting is
  the owner. Every other Google account is rejected.
- Source code: [github.com/AnthonyMDev/icloud-mcp](https://github.com/AnthonyMDev/icloud-mcp), a fork of
  [mike-tih/icloud-mcp](https://github.com/mike-tih/icloud-mcp). See `FORK.md` for the security changes.
